# Repository Architecture

## Repository Organization

| Directory | Responsibility |
|---|---|
| docs | Institutional and technical documentation |
| research | Research concepts and experiments |
| infrastructure | Scientific computing and data infrastructure |
| environments | Sandboxes and benchmarks |
| datasets | Dataset specifications and manifests |
| evaluation | Evaluation protocols and results |
| tools | Research and development tools |
| protocols | Formal research protocol families |
| assets | Visual and supporting research materials |

## Protocol Separation

### MetaGate / Genesis
Governed intelligence architecture, authorization, coherence evaluation, and consequence-aware reinforcement.

Location: protocols/metagate-genesis/

### GHOST
Procedural research environments, sandbox specifications, state systems, and benchmark development.

Location: protocols/ghost/

## Repository Principles

1. Preserve research provenance.
2. Separate conceptual specifications from implementation.
3. Document experimental assumptions and results.
4. Maintain clear protocol boundaries.
5. Make artifacts reproducible wherever practical.
